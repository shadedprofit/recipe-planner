# Codex Support Docs

Codex loads repository instructions from `../AGENTS.md`. This directory is for
optional supporting material such as workflow notes, templates, or skill ideas.

Do not put critical project rules only in `.codex/`; keep them in `AGENTS.md`
or link to them clearly from there.

Suggested contents:

- `notes/`: optional implementation or workflow notes.
- `skills/`: project-specific Codex skill drafts or usage notes.
